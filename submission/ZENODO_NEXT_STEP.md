# Zenodo archival: next human step

No Zenodo DOI has been created or claimed in this repository.

After the public GitHub release `v1.0.0` exists:

1. Sign in to Zenodo using the authors' authorized account.
2. Connect the GitHub account if it is not already connected.
3. Enable `Ranjan-V/JAIR-Fairness-After-the-Decision` in the Zenodo GitHub
   integration.
4. Confirm or recreate the GitHub release `v1.0.0` so Zenodo archives it.
5. Wait for Zenodo to mint the real DOI and verify the archived files.
6. Add the real DOI to `README.md` and `CITATION.cff`.
7. If appropriate, add the DOI to the manuscript reproducibility statement
   and the JAIR submission metadata while retaining the GitHub development URL.

Never substitute a placeholder DOI for the identifier actually issued by
Zenodo.
